# CashTrack Backend (FastAPI)

## Run locally

```bash
python3 -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
pip install -r requirements.txt
python3 -m uvicorn app.main:app --reload --port 8000
```

Visit http://localhost:8000/docs for interactive API docs (auto-generated by FastAPI).

## Run tests

```bash
python3 -m pytest tests/ -v
```

## Switching to Supabase Postgres (when ready to deploy)

1. Create a Supabase project, grab the Postgres connection string from
   Project Settings -> Database -> Connection string (URI format).
2. Set it as an env var before starting the app:
   ```bash
   export DATABASE_URL="postgresql://postgres:[password]@[host]:5432/postgres"
   python3 -m uvicorn app.main:app --port 8000
   ```
3. Install the Postgres driver: `pip install psycopg2-binary`
4. No other code changes needed — `app/database.py` reads `DATABASE_URL`
   and SQLAlchemy handles the dialect difference.

## Files

- `app/database.py` — engine/session setup
- `app/models.py` — ORM models (Expense, UserStreak, Settings)
- `app/categories.py` — the locked 7-category -> bucket mapping
- `app/streak.py` — streak logic, driven by server-clock IST date only
- `app/summary.py` — 70/20/10 aggregation + heatmap math
- `app/schemas.py` — Pydantic request/response contracts
- `app/main.py` — FastAPI routes
- `tests/test_streak.py` — streak edge case tests

## Known deviations from the old Express/JSON prototype (intentional)

- Streak advancement uses server-clock IST date, never the user-editable
  `expense_date` — prevents backdating a streak repair.
- Unknown category raises an error instead of silently defaulting to "Needs".
- Heatmap daily threshold uses the real days-in-month, not a hardcoded 30.
